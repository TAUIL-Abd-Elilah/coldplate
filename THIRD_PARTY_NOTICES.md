## Generated media

Two narrated renders of the same script ship here. They differ only in how the
speech was produced, and the reason there are two is a licence question we could
not close from inside the repository.

| file | narration | position |
| --- | --- | --- |
| `demo/coldplate_submission.mp4` | Microsoft Edge read-aloud service, via [`edge-tts`](https://github.com/rany2/edge-tts) | redistribution rights **not confirmed** |
| `demo/coldplate_submission_local_voice.mp4` | local synthesis, [Piper](https://github.com/OHF-voice/piper1-gpl) with `en_US-ljspeech-high` | **no service terms apply** |

**The canonical render.** `edge-tts` is LGPL-3.0 and is an optional, isolated
build dependency in `requirements-video.txt` — not vendored, not linked, and not
imported by anything that runs during a normal review, so its copyleft does not
reach this repository's Apache-2.0 sources. That was never the concern. The
concern is that the audio comes from a remote Microsoft service whose terms
address reading pages aloud in a browser, and **we hold no written confirmation
that its generated voice may be redistributed in a prize submission.**

**The local render.** `demo/coldplate_submission_local_voice.mp4` removes that
question rather than arguing about it. The speech is synthesised on the build
machine, so no service and no service terms are involved. Being precise about
the pieces:

* the voice, `en_US-ljspeech-high`, was trained from scratch on the
  [LJ Speech dataset](https://keithito.com/LJ-Speech-Dataset/), which is
  **public domain**. Its ONNX weights are downloaded once and pinned by SHA-256
  in `scripts/build_demo_video.py`; a mismatched digest refuses to narrate;
* `onnxruntime`, which executes the voice, is **MIT**;
* `piper-tts` 1.7.0 is **GPL-3.0-or-later**, because it links espeak-ng for
  phonemization. This repository does **not** redistribute it. It is a build
  tool listed in `requirements-video.txt`, in the same position as ffmpeg, and
  a GPL program's output is not a derivative work of the program — the same
  reason a binary compiled by GCC is not GPL. What is redistributed here is the
  rendered MP4.

Everything else in both videos — every frame, figure, number and caption — is
generated by `scripts/build_demo_video.py` from this repository's own committed
results, and the narration text is `DEMO_SCRIPT.md`, which is ours. The two
renders share one poster, and the build **asserts** that their first slides are
byte-identical rather than assuming the visual track is voice-independent.

Regenerate either one:

```bash
python scripts/build_demo_video.py                                  # canonical
python scripts/build_demo_video.py --engine piper --variant local_voice
```
